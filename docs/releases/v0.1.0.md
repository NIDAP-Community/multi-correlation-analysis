Before publication, the local R fixture and the container's public-interface smoke test completed successfully. The smoke test exercised category-specific Luminal, HER2, and pooled (`all`) outputs and verified the expected artifact set.

## Scope

This release provides portable category-specific correlation matrices, p-value and FDR matrices, circle heatmaps, summary/provenance tables, and optional L2P gene-symbol normalization. It is intended for research use.
